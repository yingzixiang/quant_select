当用户要求总结量化选股月度报告时，按以下流程执行：

1. 定位报告文件：
   - 如果用户指定了月份（如 2026-05），读取 `output/report_{month}.md`
   - 否则 `ls output/report_*.md` 取最新生成的文件
2. 阅读报告内容，按以下结构输出摘要（300-500 字）：

```
## 量化选股月度摘要 — {月份}

### 一、宏观环境
- 宏观总分及定性判断
- 偏正面和偏负面的关键指标各列举 2-3 个
- 一句话总结当前宏观环境

### 二、仓位与风格
- 股票/债券建议配比
- 大小盘、价值/成长风格占比及判定逻辑

### 三、组合概览
- 入选数量，得分最高的前 5 名（代码、名称、行业、得分）
- 行业分布概况，平均 PB / ROE

### 四、风控关注
- 是否通过，每项提醒/违规及简要说明

### 五、一句话总结
- 本月调仓策略的关键结论
```

注意事项：
- 通俗中文，让非量化背景的人也能看懂
- 正面信号用 ✅ 标注，风险信号用 ⚠️ 标注
- 代理计算或手动输入的指标需指明
- 保持数据原始精度，不要四舍五入
